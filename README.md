## Overview

The **PV Emulator Hardware** project aims to implement a solar panels simulator. The behavior of a solar panel based on the **single-diode model**. This emulator is designed for use in laboratory environments and embedded systems testing, such as MPPT algorithms.

## Repository Organization

- `doc`: Technical documentation.
- `hardware`: Hardware design files and outputs.
- `simulation`: LTspice model used for validating the solar panels behavior.
